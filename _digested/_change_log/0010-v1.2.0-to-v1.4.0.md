## 核心主题

副标题可以是"**把 v1.2.0 的新架构跑起来，并支付它的运维代价**"。五条主线：

1. **chord 在 v1.3.0 完成第二次收口**（不是 v1.4.0）：公开面整体重画，协议从"没有版本协商"直接到 **4**，并首次出现"必须由应用提供的 principal / placement"。
2. **durable 把"等待"变成持久状态**：`sleep` 从 phase 内的阻塞调用变成 `sleeping` 任务状态，SQLite schema 因此升到 v2 且**不可回退**。
3. **telemetry 升为横切层**：ai/chord/durable 三包共用，chord 把 `Context.telemetry` 设为必需成员；durable 的事件/指标名 schema 化。
4. **模型目录变成"服务已发布客户端的运行时数据面"**：发布前必须证明旧客户端能读，否则先升 `MINIMUM_PI_VERSION`；release 必须先 pin 目录再构建。
5. **client identity 统一**：UA 与 attribution 由 ai 一处决定，经 agent/coding-agent/durable 透传。
