## 核心主题

这不是维护性 catch-up，而是 **1.0 前后的"大收缩 + 大统一"**：

1. **pi-agent-core 断崖瘦身（7fd478a2e，341 文件 −105,456，占全仓删除量 75%）**：agent 包源码只剩 `agent.ts` / `agent-loop.ts` / `proxy.ts` / `stream-fn.ts` / `types.ts` / `index.ts`（index.ts 5 行）。Harness/Lane/driveOperation、session、pico3、compaction、skills、prompt templates、harness tools、内置工具、telemetry schemas、search types 全部移除；`./node`、`./harness/*`、`./experimental/pico3` subpath exports 与 uuidv7/pi-telemetry re-exports 一并删除。commit message 自述："pi-agent-core now contains only Agent, the agent loop, the proxy stream, and their types."
2. **durable 接盘成为持久会话事实层**：13 文件文档壳 → 60 文件完整运行时（净 +47.8k），Packages 15–23 全落地（task runtime、first chat/tool turn、inbox/usage/view、结构化并发、compaction、extensions + per-conversation agents、lifecycle conformance、task graph view）。`packages/session-backends` 整包删除（−4,397），SQLite 能力由 `durable/src/storage/sqlite/` 吸收并**异步化**（PR #10232 线）；memory/JSONL/SQLite 三后端全部进入公开 exports（`./storage/*`）。
3. **两个新包落地（8562bcf66 "codemode and MCP"，closes #10040，0.99.0 发布）**：`packages/mcp` = 零 pi 依赖（仅 cross-spawn）的独立 MCP 客户端——传输中立核心 + stdio/Streamable HTTP/in-memory 测试传输 + OAuth（改编自官方 MIT TS SDK v1.29.0），CI 跑 pinned 官方 conformance 套件×3 协议版本对照 `baseline.json`；`packages/codemode` = QuickJS-WASM 沙箱（唯一依赖 quickjs-wasi），worker 线程跑模型写的 JS、注入工具暴露为 `tools.<name>(args)`、嵌套调用不进 LLM 上下文。coding-agent 的 `extensions/mcp|codemode|tool-search` 是消费方（方向 coding-agent→mcp/codemode），核心 agent 只留通用机制：工具 exposure 五档 `direct|model-only|codemode|deferred|hidden`（extensions/types.ts:509）、`prepareLoadout()`、有界嵌套调用（`nested-tool-calls.ts:26-31`，256 calls / 8KiB per call / 32KiB 总量）。**pi 正式采纳 MCP 客户端生态**——v0.86.1 时源码零实现。

## 版本跳跃与 1.0 语义（仓库级审计结论）

- **0.87.1 → 0.99.0 直接跳 12 个 minor，仓库内零解释**。circumstantial 证据：0.99.0 背全部 API breaking + codemode/MCP 上线（8562bcf66 单笔 143 文件 +17,616），0.99.1/.2 三天三发快速修补，10-1 即 1.0.0——形态是**压缩的 pre-1.0 载体系列**。
- **1.0.0 无任何稳定性/API 冻结承诺**：根 README 与 CONTRIBUTING 零改动，全仓无 stability 声明；`.pi/skills/release.md` 仍写 "**No major releases**"（已被 1.0.0 事实打破且未更新）。1.0.0 自身携带 breaking（harness 删除、server 签名）——更像**里程碑/营销版本**（codemode+MCP、fullscreen 默认、leaner codemode 为卖点）。
- 发布纪律在加强：每次 release 前有独立 changelog 审计 commit（92fc452c5 等）；lockstep 版本制不变。
- **发布管线在 1.0.0 未变**：npm-shrinkwrap 仍随包发布（生成脚本零改动）；**kill-shrinkwrap 分支**（d9d7a25eb，自 v1.0.0+1 分出，与 `7fbbd5f4a` 平行未合并）已就绪——删 shrinkwrap+脚本，理由 #5653（阻碍 npm dedup pi-ai 与安全覆盖），是下一个 1.0.x 的既定方向。发布机制：tag → build-binaries.yml，npm trusted publishing（OIDC），R2 marker。
- CI：新增独立 `mcp-conformance` job（a4715ec9b）；二进制冒烟加 codemode worker 验证（scripts/smoke-test-codemode-binary.mjs，#10204 回归防线）。
