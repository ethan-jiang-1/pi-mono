## 主题详述

### 1. 新工具：PowerShell（coding-agent）

- 新增 `packages/coding-agent/src/core/tools/powershell.ts`（+67）——内置 PowerShell 工具（#8512），SDK 的 builtin tools 也同步加入（`sdk.ts` 引入 `createPowerShellTool`）
- 对 `_digested/` 的意义：它是继 bash 之后第二个脚本执行工具，TUI 侧和工具覆盖表需要提及

### 2. settings / model / thinking 持久化语义（coding-agent + tui）

- `setModel` / `cycleModel` / `setThinkingLevel` / `cycleThinkingLevel` 全部接受新的 `ModelMutationOptions { persist?: boolean }`（`agent-session.ts:256`）——`persist: true` 时写入全局 defaults（`ctrl+s persists /model`，settings-selector 的 `/model`、`/thinking` 命令）
- 默认 thinking 从 settings 移到 per-model 覆盖：`settingsManager.getModelThinkingLevel(provider, id)` 先查 per-model 再回落全局（`sdk.ts`）
- "get rid of --default and global model"：移除全局默认 model 的 `--default` 语义（settings-selector 重构，新增 `settings-submenu.ts` +258）
- 移除 settings-selector 里的 token estimate 展示

### 3. wire 协议的一个小增强：`toolcall_start` 带 id/toolName（coding-agent）

- `json-event.ts` 重写：`message_update` 的 `toolcall_start` delta 现在**保留 `id` 和 `toolName`**（从 partial content 提取，之前被 `WithoutPartial` 剥掉）；其余 delta 仍剥 `partial`。docstring："Cumulative usage, tool-call ids, and tool names remain available"
- **不改变** v0.84.0 的增量语义本身——`message_update` 仍只带 delta、无累积 message；只是 toolcall 的首帧现在多了两个恒定大小字段，便于外部 UI 关联 tool card

### 4. compaction / branch-summary 微调（coding-agent）

- `compaction.ts`（+78）：与"zero-usage 自动 compaction"（回归 8328）相关——遇到 persistent API error（如 529）或 malformed zero-usage 的处理（`agent-session.ts:2124` 附近注释）
