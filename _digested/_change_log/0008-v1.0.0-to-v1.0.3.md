## 核心主题

1.0.0 定形后的第一个快节奏周期：三天三 patch + 一天成包。主线是**执行环境从本机抽象变成跨机器契约**，副线是工具选择语义纠偏与沙箱加固：

1. **pi-env 单日成包（`ba03e03f2` → `b7dfc049e`，post-v1.0.3，Unreleased）**：Mario Zechner 一人 12 提交（10-05 12:50–17:32），`packages/env` = `@earendil-works/pi-env`——durable `ExecutionEnv` 的**跨机器实现**：TS 客户端（`Connection` 帧协议 `connection.ts:166`、`RemoteExecutionEnv` `remote-env.ts:351`、`RemoteWatcher`、`ssh.ts` bootstrap）+ Rust daemon（~3,100 行，仅 encoding_rs/notify/serde_json 三个 pinned 依赖）。核心承诺是语义等价（`docs/semantics.md`）：RemoteExecutionEnv 的结果 == NodeExecutionEnv 跑在同一远端机器，conformance + differential 双测试合同锁定。daemon 按 **SHA-256 前 32 位命名**部署到 `~/.pi/mobile/tools/`、每次启动前哈希验证；ssh 零转发/BatchMode/应用自带 known-hosts + host key 带外指纹确认；Windows 全走 PowerShell（base64 行 + `PI-ENV-END` 标记上传对抗 sshd 不传 stdin EOF、文件索引身份对抗 NTFS tunneling、ENOTDIR 合成、默认轮询 watch）。支持 Linux/macOS/Android(Termux)/Windows × x64/arm64 8 目标交叉构建（`env-daemons.yml`），daemon 随 npm 包发布（build-binaries.yml download artifact → `packages/env/bin`）。**monorepo 内零消费者**，依赖方向 env → durable+chord；coding-agent 的 ssh 扩展路线（examples/extensions/ssh.ts）不受影响，两线并存。
2. **durable ExecutionEnv 能力面大扩（v1.0.3，4 条接口级 Breaking，一晚四连 feat）**：`4748c627a` argv exec（`Shell.exec()` 收 `string | readonly string[]`，数组直接 spawn 不经 shell——宿主拼命令永远不必做引号转义）+ `openBinaryReader`/`openDirReader` + **env-conformance 套件**（`src/testing/env-conformance.ts`，511 行，durable 第二条 conformance 线）；`cdf79797b` 输出窗口 `window/skipped`（远端可省略窗口外输出但必须精确报告省略量，被省略文本永不可能进保留尾部）；`a19c09d9b` `BinaryReader.scanLines()` + BOM 语义修正（流式 U+FEFF 只在流首丢）；`a84510819` `FileSystem.watch()`——`NodeFileWatcher` 的设计核心是**原生事件只触发 rescan、变化 = 快照差分 + 事件路径**，随后三天三连平台修复（Windows 强制轮询 864777ba6、macOS FSEvents 500ms settle 1965a8069、覆盖五修 cd60a5b99）。
3. **`--tools` 语义重做 + hidden tools prompt 泄漏修复（`04b97ef00`/`c30840c2e`，Unreleased）**：旧行为传 `--tools read,bash` 会把全部 `mcp__*` 工具 unregister（`pi --tools codemode` 丢光 MCP server）。新语义两层：**allowlist 选"声明面"，exposure 管"可达面"**——未命中的 MCP 工具保持注册、只经 codemode/tool_search 到达（`_isAllowedTool`/`_isActivatable`/`_allowlistFiltersMcp`，agent-session.ts:445,1523,1535）；条目支持 `*` pattern（`createToolNameMatcher`，mcp-servers.ts:21）；新增 `--no-mcp`（loader 层过滤 builtin:mcp）。注意这**同时改变 SDK `createAgentSession({tools})` 行为**，上游只记 Fixed 未提迁移。hidden tools 修复：rules/工具列表改基于 declaredTools（system-prompt.ts:150-161），skills hint 新增 `"indirect"` 第三态，guidelines 迁入 codemode 工具声明（`ToolLoadout.getPromptGuidelines`，types.ts:550）。
