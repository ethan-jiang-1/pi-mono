## 主题详述

### 1. compaction / turn 边界正确性（本轮主线，coding-agent + agent）

- **`6b36eb592` 移除 compaction 的显式 toolChoice**（fixes #8649/#8638）：把 v0.84.3 刚加的 `toolChoice: "none"` 从 `completeSummarization` options 里删掉（`core/compaction/compaction.ts` 原 ：579 行）。摘要中对 `toolCall` 块的拒绝**保留**（现经 `getSummarizationFailure`，:545/:715/:1000；branch 侧 ：357）。注意：v0.84.3 的 toolChoice 一直在 **coding-agent 侧** `core/compaction/` 文件（1012 行），不是 agent 侧 `harness/compaction/`（848 行，本轮未动）——上一轮 3.1 警示引用 ：579/:706 时未区分两个同名文件。
- **`97fa14e39` 拒绝截断的 summary**（closes #7048）：新增导出 `getSummarizationFailure(response, label)`（`core/compaction/compaction.ts:545`）——`stopReason` 为 `error` 或 `length` 都返回失败，**截断的 summary 不再被当作 checkpoint 持久化**。三个调用点：generateSummaryWithUsage（:715）、generateTurnPrefixSummary（:1000）、generateBranchSummary（branch-summarization.ts:357）。
- **`56700d42e` compact before post-tool model requests**（#8782，closes #6879）——**breaking**：agent-loop 的 `prepareNextTurn` / `prepareNextTurnWithContext` 改为**只在 `shouldStopAfterTurn` 与 queued-message 检查判定循环将继续之后、下一 turn 开始前**才运行（`agent-loop.ts:176-198`）；final turn 不再触发，收尾工作应移到 `agent_end`。coding-agent 侧新增 `AgentSession._compactBeforeNextAssistantResponse()`（`agent-session.ts:543`，挂进 `_installAgentNextTurnRefresh` 链 :568-569）：工具结果追加后、下一 assistant 请求前做阈值压缩，同一 run 内完成。run 终止且无排队消息时跳过（docs/compaction.md:37）。
- 配套：prepare 可能长时间运行（如压缩），prepare 后**补轮询一次 steering**（仅当先前轮询为空，`agent-loop.ts:191-195`）；TUI 进度指示从 `agent_start` 推迟到 `turn_start`，避免压缩期间显示假进度（interactive-mode.ts:2162/3197）。
