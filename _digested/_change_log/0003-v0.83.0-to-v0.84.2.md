## 核心主题

这是一次**架构换代**，不是渐进迭代。虽然只有 2.5 周，但 v0.84.0（2026-08-06）集中了多个 breaking change：

1. **Agent harness session 模型重写为 v4**——lane-based `Session`/`SessionStorage`/`SessionRepo`，旧的 JSONL/in-memory repository API 直接删除
2. **client/server/protocol 三件套成型**（experimental）——二进制 CBOR 协议 + 传输无关的 PiClient + PiServer，这是未来替代 RPC mode 的方向
3. **JSON/RPC `message_update` 事件改为纯增量 delta**——移除累积 `message` 字段，客户端必须自己拼装
4. **Fullscreen TUI 模式**——运行时可切换的全屏模式 + transcript 搜索 + Mermaid/LaTeX 渲染
5. **Auth/model registry 全面加固**——一批 breaking：refresh 语义、header 语义、OAuth signal 传递

## 五大主题详述

### 1. Harness session v4（agent 包，最大 breaking）

- 旧 session 模型（`Session` + `SessionStorage` + `SessionRepo` 的前身）→ **v4 lane-based** 模型：durable operation records、global facts、shared sequence numbers、tree-scoped lane views
- **删除**：legacy JSONL 和 in-memory repository API → 替代为 v4 `JsonlSessionRepo` / `InMemorySessionRepo`
- v2 session 和 `AgentHarness` API 从 experimental 入口**转正为默认导出**，experimental subpaths 删除
- 新增必需的 `FileSystem.renameFile()`——JSONL 原子发布（fork 和 torn-tail 修复不再产生半写文件）
- 新查询：`Session.findEntriesOnBranch()` / `findEntryOnBranch()`（bounded，带 traversal/filter/order/limit options）、`findOpenOperations()`（recovery 查询）
- `AgentHarness` v2 scaffold 落地，未完成的 operation 路径 reject with `HarnessNotImplemented`
- `Agent.reset()` 在 active run 期间现在会 reject（之前会清掉正在跑的 transcript）
- `AgentOptions.shouldStopAfterTurn`——turn 完成后优雅停止
- 开发过程文档 `harness-v2.md`/`harness-v3.md` 最终合并为 `agent/docs/harness.md`

**agent/src/index.ts 导出面变化**：

```
删除:  harness/session/jsonl-repo.ts, jsonl-storage.ts,
       memory-repo.ts, memory-storage.ts, repo-utils.ts
新增:  harness/result.ts, harness/session/index.ts,
       harness/telemetry.ts, search/index.ts,
       大块 @earendil-works/pi-telemetry 类型/工具 re-export
```

**新目录**：`agent/src/harness/session/{jsonl/, testing/}`、`agent/src/search/`、`harness/session/` 下新增 `context.ts` / `state.ts` / `types.ts` / `jsonl.ts` / `memory.ts`；`harness/` 顶层新增 `events.ts` / `messages.ts` / `reducer.ts` / `result.ts` / `telemetry.ts` / `prompt-templates.ts`

### 2. Client/Server/Protocol 三件套（experimental，但方向明确）

| 包 | 内容 |
|----|------|
| `packages/protocol` | runtime-neutral schemas + CBOR 编解码 + 字节流 framing。协议版本 1：4 字节大端长度前缀 + 1 个 definite-length CBOR item。首条消息必须是 `hello`（带 `PROTOCOL_VERSION`）。请求/响应 envelope + server event envelope。Session snapshot 是权威状态，progress event 只是 UI 提示 |
| `packages/client` | 传输无关的 `PiClient`，通过 `ByteTransport` 接口交换消息（WebSocket/Unix socket/任意有序字节流）。`session.subscribe(snapshot => ...)` 模式，无 Node 专属 import |
| `packages/server` | `PiServer` session server，提供 unix socket transport（`createUnixServer`），`PiServerService` 接口挂 storage/modelRegistry |

**意义**：这是 `_digested/integration/` 描述的 "SDK（进程内）+ RPC（JSONL over stdin/stdout）" 之外正在成型的第三条集成路径。`packages/coding-agent/src/modes/rpc/` 目前仍在（jsonl.ts / rpc-client.ts / rpc-mode.ts / rpc-types.ts 都活着），未被替代，但长期方向值得跟踪。

### 3. `message_update` 事件改纯增量（直接影响 integration/04-event-model.md）

- JSON 和 RPC 的 `message_update` 现在只 emit `assistantMessageEvent` **delta**，移除了累积的 `message` 和 `assistantMessageEvent.partial` 字段（它们导致 quadratic output growth）
- 需要 partial message 的客户端必须在 `message_start` 和 `message_end` 之间自己拼 delta；`message_end` 仍是权威
- 修复：`message_update` 在 streaming 时不再丢 cumulative usage

### 4. Fullscreen TUI 模式

- 运行时在 regular/fullscreen 模式间切换；sticky editor/footer、独立滚动的 transcript、拖拽滚动条
- 全屏 transcript 搜索（`Ctrl+Shift+F`，增量高亮，`Enter`/`Ctrl+G` 导航）
- 双击选词、三击选段、粒度感知拖选；半页滚动；Mermaid 图和 Unicode 数学渲染
- `tui-alt-screen.ts` 为新核心文件（18 commits）
- `defaultTools` setting：全局或按项目配置启动内置工具集；`--use-theme` 指定单次运行主题

### 5. Auth / model registry 加固（ai + coding-agent，多个 breaking）

- `ModelsStreamTransforms` 改名 `ModelsRequestTransforms`（header 变换现在作用于所有已认证 provider 请求）
- `ModelRegistry.getApiKeyAndHeaders()` 返回 `ProviderHeaders`（`string | null` 值，保留 null 删除标记）
- `ModelRegistry.refresh()` 接受 `ModelsRefreshOptions` 返回 `ModelsRefreshResult`（不再吞掉取消和 provider 错误）
- `ModelRuntime.setRuntimeApiKey()` 改为接受 auth cancellation options
- config-form extension 的 OAuth `refreshToken()` 必须接受并尊重 abort signal
- 动态 provider refresh：raw `context.store` 访问 → 只读 `context.stored` snapshot + generation-checked `context.publish()` 事务
- 新 provider：Baseten（含原生 `chat_template_args` 推理控制）、Qwen Token Plan Individual；`pi auth check` 命令
- deferred provider request contracts：durable response handles、authenticated fetch/cancel dispatch、faux-provider
- 任意 OpenAI-compatible `samplingParams` 透传（`Model.samplingParams` + `StreamOptions.samplingParams` + per-request override）；vLLM `thinking_token_budget`
- `PI_EXPERIMENTAL=1` 下内置 read/bash/edit/write 工具启用 strict JSON-schema constrained sampling

### 其他值得记录

- **Extensions**：`BeforeToolCallResult.terminate`（blocked tool call 可终止整批）；`pi.sendUserMessage()` 新增 `expandPromptTemplates`；`AGENTS.override.md` 按目录替换 context files
