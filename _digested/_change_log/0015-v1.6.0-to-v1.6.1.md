## 核心主题

一句话：**"凡用 `in` 辨 union 成员者，改为 tagged union"**——v1.6.1 的 AGENTS.md 新规则被同 release 在 durable/chord 的 API 上全面执行；另加决策模型（classify）进 codemode、每类 transcript notice 独立设置、以及一条跨五包的性能修复线（#12224 行扫描 O(n²)）。

1. **tagged-union 扫荡**（durable 7 条 Breaking、chord 3 条 Breaking + 1 条 sync 变更）：`CommitResult`、`ToolPark`、`Wrap`、`onYield` 结果、`beforeCompact` 结果、`SignalState`、`SeriesResult`、`RolloutHost`、`PluginSource` 全部改为 `{ kind: ... }` 判别；`Conversation.submit(tx, draft)` 改名 `admit(tx, draft)`；chord sync（experimental）删掉 writer epochs。
2. **决策模型进 codemode**：`models.classify()` 可调 GitHub Copilot 的 `gpt-6-luna-decisions` 与 Radius 的决策模型；结果带 `responseId`（OpenRouter System One 用真实 generation ID 与实付成本替换目录估价）。ai 层新增 `pi-decision` API（`POST <baseUrl>/decision`，类比 `pi-messages` 的通用决策协议）。
3. **notice 设置拆分**（coding-agent 唯一 Breaking）：`showCacheMissNotices` 一个开关拆成 `notices.cacheMisses`/`cacheWarming`/`compactionCosts`/`reasoningDrops` 四个（旧值迁移到四个；`getShowCacheMissNotices()`/`setShowCacheMissNotices()` 删除，换 `getNotices()`/`setNotice()`）。
4. **#12224 O(n²) 行/事件扫描修复线**：同一个根因（每个 chunk 重扫未完行）在 ai（Anthropic/Codex/Mistral/pi-messages SSE）、mcp（Streamable HTTP SSE）、chord（sync batches 与 `importStore` JSONL）、durable（Node 环境 text line reader）、tui（`StdinBuffer` bracketed paste）五处各自修复。大行（多 MiB 工具结果/图片消息/粘贴）从平方时间降回线性。
5. **Windows 收尾**：bash 工具经 `git var GIT_SHELL_PATH`（Git 2.47+）找 Git Bash（不再误走 WSL `bash.exe`）；durable `NodeExecutionEnv` 同修；关窗/关标签页触发 SIGHUP 处理（`session_shutdown` 不再跳过、子命令不再残留）；`pi update` 在 WSL 里调 Windows 安装时明确拒绝。

## 三个必须先建立的判断

### 1. tagged-union 扫荡是一次"规则先行、代码跟进"的机械改约——迁移是纯模式替换

AGENTS.md 新规则（本轮新增）：**"永远不要用 `in` 区分 typed union 成员（`"report" in entry`）——做成 tagged union（`kind` 字段）并 switch on tag。`in` 只留给信任边界上的未知类型、特性检测、以及版本升级才会变的存储/线上格式（要写注释说明）"**。同 release：

- **durable**：`ToolPark` → `{ kind: "sleep", checkpoint?, until?, signals? }` / `{ kind: "wait", checkpoint?, on, policy }`（扁平，替换 `{ sleep: {...} }`/`{ wait: {...} }`；result 无 `kind`）；`Wrap` → `{ kind: "tool", tool, wrap }` / `{ kind: "section", section, wrap }`（建议用 `wrapTool()`/`wrapSection()` 构造）；`onYield` 结果 → `{ kind: "continue", continue }` / `{ kind: "tasks", tasks }`；`beforeCompact` 结果 → `{ kind: "decline" }` / `{ kind: "summary", summary }`；`SignalState` → `{ kind: "value", value }` / `{ kind: "expired" }`（存量 signal memo 兼容读取）；`CommitResult` → `{ kind: "stored", stored }` / `{ kind: "refused", stored, refused }`；`submit(tx, draft)` 事务形式改名 **`admit(tx, draft)`**（`submit(draft, context)` 不变）。
- **chord**：`RolloutHost` → `{ kind: "reloaded", host, report }` / `{ kind: "stopped", host }` / `{ kind: "failed", host, error }`（worker 对 reload 的回复同样 `reloaded`/`reload_failed`）；`PluginSource` → `{ kind: "git", git, ref }` / `{ kind: "npm", npm, version }`；`SeriesResult`（`ChordStore.commitSeries`）→ `{ kind: "stored", stored }` / `{ kind: "refused", ... }`——与 durable `CommitResult` 同形（两包 API 对齐）。sync（experimental）：writer epochs 整体删除（`uploadSession` 不收 epoch、结果无 `stale_epoch`——"没有任何 remote 发过 epochs"）；新增 `remote_empty` 报告（remote 的副本被删过，host 可忘掉同步状态全量重来）。

对 `_digested` 的含义：凡引用 durable/chord 状态形状的代码片段（0011 记录的 `CommitResult = { stored, refused? }` 即其一）**全部需要按 1.6.1 形式重写**；`harness` 专题里的"读取 refused 字段"示例要改成先 `switch (result.kind)`。

### 2. 决策模型（classify）第一次有了协议层——ai 长出第三种请求类型

- ai：`pi-decision` API（`POST <baseUrl>/decision`），与 `pi-messages`（chat）并列的通用决策协议，Radius 网关先用；`gpt-6-luna-decisions`（GitHub Copilot）支持文本与图像；`responseId` 进分类结果（OpenRouter System One 用真实计费替换估价）。
- coding-agent/codemode：`models.classify()` 面（含 Copilot `gpt-6-luna-decisions`、Radius 决策模型、既有 Microsoft-Decision-1）；Copilot 登录/刷新后只列账号可用的决策模型（修 400）。
- 定位：classify 是"有类型的决定 + 概率"，不是 chat 的别名——`_digested` 的 ai 层次描述（chat/image/classifier 模型统一进 `Model`/`Provider`）需要补"决策协议独立成 API 形态"这一层。

### 3. notices 拆分是 settings 面的一次 Breaking 重排，`blockedKind` 是扩展 dialog 的小但完整的协议增量

- notices：`/settings` 的 Notices 区四开关；旧 `showCacheMissNotices` 值迁移到全部四个；SettingsManager 两方法删除。引语料里所有 `getShowCacheMissNotices` 示例失效。
- `ctx.ui.select()/confirm()/input()` 增 `blockedKind`：OSC 7501 程序状态可标 `permission`/`question`/`login`（如审批 select 报 `permission`）；启动前的对话框（项目信任、首次设置）也上报 blocked（多行标题只取首行；信任/首次设置报 `kind=permission`，#12439）。
